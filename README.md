# transporteservico-urbs-data-2026

Snapshots dos dados públicos de operação e movimentação dos ônibus da URBS (Curitiba), publicados como arquivos estáticos.

## Fonte dos dados

Os dados são obtidos do webservice da **URBS - Urbanização de Curitiba S/A**, em [transporteservico.urbs.curitiba.pr.gov.br](https://transporteservico.urbs.curitiba.pr.gov.br), acesso autenticado concedido pela própria URBS.
